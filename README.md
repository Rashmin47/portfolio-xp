# portfolio-xp

Personal portfolio for Rashmin Sharma — built with Next.js 15 (App Router), Tailwind v4, and Motion.

## Getting started

```bash
npm install
npm run dev   # → http://localhost:3000
```

The production build needs `SITE_URL` (e.g. `SITE_URL=https://rashmin.com.np npm run build`); without it the build fails, because canonical URLs, Open Graph URLs and the sitemap depend on it.
